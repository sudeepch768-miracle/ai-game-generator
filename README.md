## 🌟 Overview
**REALITY → PLAY** takes any user-uploaded image—a hospital room, train station, bank vault, snowy mountain, restaurant kitchen, airport, or messy desk—and analyzes its architectural layout, color spectrum, landmark structures, and ambient lighting to generate a playable, multi-sector 2D arcade adventure in seconds.

The game is rendered in an optimized HTML5 Canvas 2D engine featuring directional vision cones, patrol paths, tactical dash and EMP stun abilities, interactive NPCs, collectible objectives, authentic props, and responsive retro sound synthesis.

## ⚡ Quick Start

### Prerequisites
- **Python 3.11+**
- **Node.js 18+**

### 🚀 1-Click Local Installation (For Anyone)
Anyone on Windows can install and play the game in seconds without manual setup:

1. **Clone or Download** this repository.
2. **Double-click `install.bat`**:
   - Automatically detects Python (or offers 1-click install via Windows winget).
   - Sets up an isolated local environment (`.venv`) and installs requirements.
   - Automatically generates a **"Reality to Play"** Desktop Shortcut with custom game icon.
3. **Double-click the "Reality to Play" shortcut on your Desktop** (or `play.bat`):
   - Launches the game in a clean, dedicated native desktop app window at `http://localhost:8000`!

---

### 🛠️ Developer & Manual Setup
#### 1. Backend Setup
```bash
git clone https://github.com/sudeepch768-miracle/ai-game-generator.git
cd ai-game-generator
python -m venv .venv
.\.venv\Scripts\activate
pip install -r backend/requirements.txt
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

#### 2. Frontend Development (Vite Dev Server)
```bash
cd frontend
npm install
npm run dev
```
Open **http://localhost:5173** (or **http://localhost:8000** for production build).

## 🛡️ Architecture & Safety
- **No Arbitrary Code Execution**: The AI synthesizes structured, strongly-typed JSON validated with Pydantic v2 schemas.
- **BFS Reachability Guarantee**: Every procedural or AI-generated map runs through a graph reachability check to guarantee the player can reach all required items and the extraction portal.
- **Intelligent Offline Fallback**: Even without an API key or internet connection, the built-in Computer Vision synthesizer analyzes pixel histograms and HSV properties to create authentic levels.
